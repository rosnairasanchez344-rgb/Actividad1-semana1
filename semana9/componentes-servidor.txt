Sistema operativo:
Es el software principal del computador. Administra los recursos del sistema y permite que las 
aplicaciones funcionen correctamente.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador.
 Se utiliza para crear aplicaciones y servidores.

Aplicación server.js:
Es el archivo donde se encuentra el código del servidor. Define las rutas y las respuestas que recibirán 
los usuarios.

Puerto:
Es el punto de comunicación por el que el servidor recibe las solicitudes. En este caso se utiliza el 
puerto 3000.

Logs:
Son registros de la actividad del servidor. Permiten verificar el funcionamiento y ayudan a
 detectar errores o problemas.
